# 预期研究｜市场已经押了什么，现实会不会超出

1. 锁定具体事件、观察截点、公布时间/时区、信息是否已公开、受影响标的、交易和投资期限。优先官方经济日历、统计机构公布日程、公司 IR/财报日程、交易所及监管事件文件。区分事件是否发生与事件结果大小。
2. 找共识：记录带时间戳的分析师/公司指引/调查中位数、范围与修订；如宏观事件查官方历史数据和公开一致预期来源，财报查营收/EPS/利润率/下一期指引的共识。搜索 "<event> consensus forecast / estimates revision / guidance / surprise / options implied move"。同源转载不计作多个独立意见。
3. 找市场实际定价：价格和成交、相关标的、期货期限结构、期权平值跨式成本或隐含波动、利率期货/概率市场（看合约结算定义、流动性、风险溢价）。期权隐含波动表示波动幅度估计，不是方向；市场隐含概率不是客观概率。无法可靠反推共识时说明代理指标。
4. 自己从驱动量推演：收入=客户×用量×价格；通胀用可观察分项；利率决策分析就业/通胀及官方沟通；政策看投票、执行与法院；用对应路径取得底层数据。建立基准、偏高、偏低与关键尾部情景。每个假设注明证据或未知。
5. 算预期差：实际/独立预测 - 当时共识，必要时除以历史预测误差或共识分歧；分拆市场更关注的变量（例如当期 EPS 与下一季度指引）。研究历史事件反应：发布前价格变化、公布后的分钟/小时/日收益、基准资产同期收益、流动性、同日其他事件；只用当时可知信息，避免后见之明。估计条件价格反应分布，而非“利好必涨”。
6. 建情景矩阵：事件结果、概率（可估时给区间及依据）、合理价格反应范围、发生时间、影响链、失效信号。预期收益=sum(情景概率×情景净收益)，扣费用、滑点和融资成本；检查概率和为1、同一风险是否重复计入。不够数据就不编造概率或具体点位。
7. 反推价格需要的条件：对于股权用公司估值路径；二元合约仅在明确结算和费用口径下反推价格所含概率；短期交易同时检查定位、拥挤、流通盘、解禁、期权到期和市场状态。标注事件已兑现、尚待兑现、反向或取消的条件。
8. 输出决策前观察表：哪些证据出来才确认、什么变化推翻、何时到期、是否有足够赔率；没有优势就写“暂无法识别优势”。研究与执行分开，未获明确授权不操作资金。

交付：带截点的预期/价格表、独立情景及推演过程、历史反应、概率与回报范围（数据允许时）、下一事件和判断失效条件。
