# 政策研究｜从原文到行为和受益资产

1. 确认国家、州/地方、主管机构、法案/条例/行政命令编号和版本。先查政府官网、官方公报、议会/国会立法数据库（美国 Congress.gov、Federal Register、Regulations.gov、相关机构；欧盟 EUR-Lex；中国政府网、全国人大、主管部门；按辖区选择）。搜索政策全名 + "text / final rule / effective date / implementation / exemptions / appropriations / guidance / enforcement"。查原始发布日期、通过、生效、合规期限、上诉、日落条款。
2. 提取条款表：原文条款/页码、具体义务、适用对象、地理范围、门槛、税率/补贴/限额、豁免、罚则、执行机构、申请/审批流程。区分提案、正式通过、实际生效、执行指引、法院限制；不要根据政客讲话直接认定成法。
3. 查动因与可执行性：政策说明、立法听证、成本收益评估、财政拨款、地方审批、监管人员/许可容量、诉讼、配套细则。识别政策目标、利益群体、实施瓶颈和关键投票/司法事件。法律允许的上限与实际可获得金额分开。
4. 做反事实：没有政策时，主体原来的成本、收益和行为是什么？政策改变的具体变量是什么？建立“条款→可计算的单位成本/收益变化→主体调整行为→供需/价格/利润变化→受影响主体”的链。举例：补贴资格→设备真实净价降低→订单增加→供应约束→谁获利；检查中间条件。
5. 测算规模：合格主体数×符合条件用量×单位补贴/成本，受预算上限、申请率、执行周期、合规成本限制。列直接、间接、替代效应、反向激励和承担成本的人。企业受益量按业务暴露度及增量利润而非新闻关键词筛选。
6. 查历史和对照：同辖区旧版政策、类似地区政策、官方执行数据；有足够数据时比较政策前后及合理对照组、检查趋势和同期干扰；没有可信识别条件就保留因果假设。
7. 与预期路径连接：市场何时得知，提案/投票/通过/生效/支付哪个时点会有新增信息；是否已经被价格消化？按延期/缩水/按期/超预期等情景测算。记录下一事件和失效条件。

交付：原文+条款映射表、真实生效和执行时间线、成本/收益变动量、传导链与利益图、情景及追踪指标。涉及法律结论应注明辖区和依据。
