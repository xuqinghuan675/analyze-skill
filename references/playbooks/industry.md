# 行业研究｜找到产业链真正的利润池

1. 确定范围：研究地区、客户类型、产品边界、产业阶段、统计单位。先找行业监管/分类代码、协会报告与政府统计；不要用所有潜在需求冒充可服务市场。
2. 搜索顺序："<industry> value chain / bill of materials / procurement / capacity / utilization / shipment / market share"；政府统计局、海关 HS 编码、能源/行业主管部门、协会、国际组织（如 IEA、OECD、UN Comtrade，按行业选择）、龙头 IR 财报及供应商/客户招标。搜索反向词 "oversupply / inventory / price decline / canceled order / bankruptcies"。
3. 列至少一条真实产品链：原材料/设备→生产→分销→终端应用。为每一层记录关键企业、商品或服务、上下游合同、价格形成机制、产能/交付周期、客户集中度。用龙头的成本/收入构成验证哪一层真正收钱。
4. 做供需底表：历史出货量、库存、价格、产能、利用率、进出口、终端客户数和每客户需求。用自下而上需求=客户数×渗透率×人均用量×单价，供给=可运行产能×利用率×良率（按行业修订）。对照第三方市场规模；避免把产业链各级销售额相加造成重复计算。
5. 算利润池：每个环节实际销量×单位毛利或收入×经营利润率（说明口径）；估计资本开支、资本回报率、现金周期、供应弹性。比较两端议价权、集中度、替代难度、技术专利/渠道/标准、转换成本。判断增长到底转成数量、价格还是利润；寻找“整个行业增长但企业不赚钱”的原因。
6. 找瓶颈和领先信号：订单→在建产能→验收/投产→实际出货→终端消化。用合同、设备交货期、建设许可、招聘、库存和价格定位供需哪边先变。分析政策、替代技术、融资、原材料和物流冲击，分别追直接受益者与利润被挤压者。
7. 找结构相似历史：如高固定成本、产能过剩、平台迁移或监管牌照。比较资本强度、需求弹性、竞争、融资和政策制度差异，再判断历史是否适用。
8. 做情景：需求、产能、单价、成本、竞争假设分别改变；输出利润池迁移和最可能受益/承压的环节。列未来可观测的领先变量及逆转条件。

交付：可核对的产业链交易图、供需/利润池表、瓶颈及变动机制、可受益公司清单（进入公司路径验证）、基准/上下行情景。禁止只用市场规模和 CAGR 结束研究。
