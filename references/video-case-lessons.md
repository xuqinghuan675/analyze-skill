## 2. X Money：研究产品时，拆功能背后的基础设施与使用场景

视频 ID：hQ0R2jk6fTI。已读自动识别片段：09:48–14:23、16:29–18:05、21:52–27:29。源文本：video/cases/payments-product/selected_transcript.md。

### 关键研究链
- 表面问题：社交平台有流量、支付功能、利息与返现，能否转化为长期金融业务？
- 第一层：资金到底由谁保管？用户界面上的品牌、平台运营主体、合作银行、存款人身份、账户安排和保险适用条件分别是什么？查官方服务协议、合作银行与监管机构原文；存款保险覆盖范围与欺诈、盗用、运营中断等风险分开。
- 第二层：用户是否信任平台处理资金？查诈骗损失额、交易量/用户数分母、投诉率、赔付责任和身份门槛；扩张是否提高欺诈、合规、客服与反洗钱成本？
- 第三层：系统是否足以承担金融活动？查 SLA、实际可用性、交易失败、重复扣款、对账与恢复机制。将社交媒体停机与支付系统停机的损失按业务现实比较。
- 第四层：平台的流量有没有支付需求？区分公共内容浏览、熟人互动、高频必需交易；网络效应必须落实到使用场景。比不同市场中客户原有的支付工具、商户接受度与切换成本。
- 第五层：补贴获客是否变成长期客户？返现、利率、获客促销带来的是活动流量、真实沉淀还是套利用户？比较去掉补贴后的留存、交易频率、每客户净收入与贡献利润。

### 迁移
任何 SaaS、支付、平台或软件产品：功能→谁实际提供底层服务→谁负责履约/赔偿→客户使用场景→用户行为和收入→单位经济。研究竞争壁垒时用真实使用、替代成本、长期留存检验，不以注册用户/下载量直接判定。 
补充：作者口述 SLA 时的数字可能存在转录误差；统一用实际百分数计算年度不可用时间，99.999%（五个9）约5.26分钟/年，99.9999%（六个9）约31.54秒/年，二者不能混用。

## 3. 长鑫存储：周期利润和技术护城河不是同一个变量

视频 ID：IFRIfQeM9Hk。已读片段：10:43–15:46、16:49–22:49、24:13–27:31。源文本：video/cases/memory-chips/selected_transcript.md。

### 关键研究链
- 先懂产品的物理限制。计算速度与数据供给速度分开，了解 GPU 计算单元为何会等待内存。研究内存墙、高带宽内存、数据接口、实际传输速度、功耗、封装与良率。理论带宽可按接口宽度(bit)÷8×每pin数据速率计算，实际吞吐受工况影响；不能从接口位宽直接推实际性能。
- 再懂行业经济。标准化 DRAM 的产品可替代性、成本竞争、建厂与设备资本开支、库存、产能供给纪律；用产能和终端需求解释价格，而不是只看总市场份额。
- 当某类产品价格上涨，追究是需求增长、供给退出、产品结构迁移，还是新增产能迟滞。例如其他企业把部分产能转移到另一高价值产品时，原产品可能出现供给紧张；用实际产能转换、报价、出货、库存验证。
- 分析具体公司时，拆分收入为产品级销量×实现单价，拆毛利为售价减单位成本，追产品等级、量产良率、客户认证和先进产品收入占比。不要将通用产品份额外推为先进产品份额。
- 高利润可能只是商品价格在周期高点，不一定代表成本领先。构造价格恢复常态、竞争产能释放、良率改善、技术升级的情景；重新计算毛利、自由现金流及资本回报。
- IPO 定价进一步查可交易股份、锁定与解禁、估值口径和投资者预期。少量流通盘导致的交易价格与可持续盈利分别分析。政策扶持、产业战略价值与股东回报也分别衡量。

### 迁移
研究芯片、光伏、钢铁、能源、航运等周期行业：技术指标→可售产能→库存/价格→单位经济→跨周期利润→估值。对“公司增长惊人”先算行业共同价格因素，再算个体成本与市场份额因素。作者提出的具体技术差距、市场份额和政策评价仍须查证。

## 4. 宇树科技：技术演示、技术成熟、真实收入、客户生产力分层研究

视频 ID：W3Xmb6GSwXw。已读片段：03:43–07:13、14:30–21:26、24:25–30:46。源文本：video/cases/robotics/selected_transcript.md。

### 关键研究链
- 技术演示不是同一种能力。分别观察遥控、预编程、特定工况自主运行、未知工况自主运行；设计同任务同工况的验证，不以视频展示自动推断具身智能水平。
- 从“能做”追到“可以投入生产”：真实工作任务、成功率、任务时长、人工干预频次、连续运行、故障恢复、泛化、维护和安全。跑步速度、动作数量等单项指标必须对应实际任务价值。
- 研发费用绝对值、研发费用率、研发人员规模、研发项目结构都需要看；同业比较还须对齐资本化口径、外部技术采购与研发阶段。研发占比高不能自动证明研发能力，绝对金额也不能单独证明研究质量。把研发投入分到硬件、运动控制、感知、智能模型及具体研发成果。
- 收入按客户和使用目的分层：科研教育、展示消费、工业/服务等真实生产。出货、签约、已交付、持续生产、客户复购分开统计；用终端客户真实收益而不是出货量推断市场成熟度。
- 追政策和公共采购：补贴、财政资金、项目合同、验收、客户来源与重复采购。区分产业政策创造的初始订单和补贴退出后的独立商业需求。
- 进一步反推估值：当前市值/同口径利润或收入只是起点；拆不同业务的成长阶段与兑现难度，再比较合理区间。同行不只看行业标签，应匹配商业模式和资本强度。

### 迁移
适用于新技术和硬件、AI Agent、外骨骼、机器人、创新药等。最重要的是将指标分四层：技术可行性、产品可交付性、使用经济性、公司财务可持续性。每层单独寻找一手数据和能推翻判断的证据。政府采购也可能产生真实使用与技术发展，不能凭客户类型直接定性需求真假；必须检查实际用途和独立付费意愿。

## 5. 万科：公司治理不能只看持股比例

视频 ID：Z44cYcYwIBw。已读片段：06:22–08:45、12:22–19:42。源文本：video/cases/property/selected_transcript.md。

- 作者从实际控制人、第一大股东、经理人持股和家族结构出发，追到外部投资人收购、董事会席位以及制度约束。研究公司必须把出资者、经济利益、投票权、董事提名与罢免权、实际经营决策权分开。
- 核对公司章程、股权披露、投票协议、董事会分类任期及表决门槛；检查不同股份类别和一致行动人。股东持股比例不直接等于董事会控制比例。
- 遇到恶意/非邀约收购，研究股东权利计划（poison pill）、分期董事会（staggered board）、友好收购方（white knight）、信义义务（fiduciary duties）及适用法律。计算触发阈值、潜在稀释、改选时间和收购成本；对实际合法性和义务范围查适用司法辖区、章程、监管文件和案例，不泛化为所有公司的统一规则。
- 对不同国家治理制度的评价要比较法律、执行、具体事件和反例；不能从一家公司推出整个市场必然如何。

## 6. 中美科技股：指数、市场宽度和个股表现要分开

视频 ID：l7YOTaKV8gc。已读片段：05:22–13:00、15:31–19:45。源文本：video/cases/equity-market/selected_transcript.md。

- 科技板块暴跌，不代表整个股市同方向同幅度变化。查指数权重、成分股涨跌比例、各行业收益与贡献。市场宽度 = 上涨成分股数÷可比较成分股总数；指数贡献按期初权重、成分股收益及实际指数方法估计；比较等权和市值加权收益，区分权重集中与广泛下跌。板块相对强弱不直接证明真实净流入，需申赎/订单等证据。
- 识别大盘贝塔和个体研究能力：单只股票盈利需扣除基准市场及风险暴露，对照同阶段替代策略；牛市获利本身不能说明选股优势。
- 指数历史回报研究须统一价格收益、含股息再投资的总回报、币种、通胀、税费、起止日期、成分股重构。长期回测仍报告最大回撤和恢复时间；不得将历史上涨推断为保证收益。
- 定投分别报告投入本金、期末市值、净收益、累计收益及资金加权收益率 XIRR；以真实日期和每笔现金流计算。不要把一次性投资年化收益、定投资金加权收益和累计收益混用。用多个起点、不同回撤/汇率情景检查结论。
- 作者对具体市场和投资方式的偏好不是研究结论；本 Skill 学习指标判读、基准比较和时间尺度的区别。

## 8. 固化到 Skill 的方法

metric-intelligence.md 是本轮独立扩展的指标手册。里面的通用指标和公式需按实际对象选择、核对原始口径；并非全部由上述视频讲授。研究的最高优先级是：

陌生术语 → 查定义与单位 → 解释实际测量对象 → 拆驱动量 → 找至少两个可能机制 → 选能区分它们的证据 → 回到真实使用/成本/合同/控制权/供需 → 判断对现金流与预期的影响 → 建立情景与可证伪条件。

禁止把“指标越高越好”“技术进步就一定能赚钱”“政策出台就一定有利”“涨幅就等于基本面”写成没有证据的规则。
