# V5 六域联动研究规程（必读）
## 路由不是分割研究
所有正式任务自动创建行业、公司、产品、政策、市场、预期六域。init --routes 指定主要研究入口（anchor），不是只做这些域。六域都要检查与决策的关联性，深度随实际问题调整。主域 primary，实质相关域 linked，影响不重要且有证据才 screened。
核心不可屏蔽：公司入口必有产品、行业、公司、市场、预期；行业入口必有行业、产品、公司、市场；产品入口必有产品、行业、公司；政策入口必有政策、行业、公司、市场；市场入口必有市场、行业、预期；预期入口必有预期、市场。多个入口取并集。非核心不是默认不查，政策/监管特别是重大投资必须评估实际影响。非公司资产把公司域落实为组织、权益及可分配收益关系；BTC 不虚构公司收入、利润或DCF。
G0 逐域记录实际对象、问题、研究重点和决策影响；G1 31主题全覆盖，原始E带topics标签，屏蔽须原始证据，核心重大缺口不得降格。G2 每个活跃域至少一个证据驱动指标卡，必要时补齐领域知识。

## 六条必须完成的跨域机制
| ID | 传导 | 关键问题 |
|---|---|---|
| L1 | 产品→公司 | 用户ROI、实际用量、客户数量、净价及服务成本，如何转化为营收、利润或可分配现金？ |
| L2 | 行业→公司 | 有效供需、产能/良率、竞争、份额与利润池如何限制收入和利润率？ |
| L3 | 政策→行业 | 已生效制度/财政/利率/贸易规则改变什么成本、资格、许可和供需？ |
| L4 | 公司→市场 | 盈利/现金流/融资稀释/权益或供给变化如何映射市场价值与交易约束？ |
| L5 | 市场→预期 | 当前价格、期限结构、报价等反推出市场已经计入哪些条件？ |
| L6 | 预期→市场 | 独立预测与隐含条件的差额何时兑现，情景价值/收益/风险如何变化？ |

每条 L 都是可被证伪的研究链，不是宣称一定存在因果。G4 引用不同端点的原始证据，明确作用机制、目标变量、时滞、条件、失效。G5 L1/L2/L4/L5/L6 默认必须实算；模型的 C 需要沿变量依赖追溯到两端同一 L 明示的证据，不允许写两段独立分析冒充联动。L3 可用有证据的定性限制，若政策影响能量化则量化。实际不相关且端点已 screened 可用 immaterial（需要两端原始证据）；无法确认的链接、计算写 material gap，不假设影响为零。G6 对每条链检查最强反例、实际复查及处理结果。G7 将每条链的计算/约束用于主问题综合模型：核心公司任务最终模型必须消耗公司、产品和行业证据，且含已通过的联动计算；其他任务至少覆盖三个活跃相关域（如果不足三个则全部），否则材料缺口导致 PARTIAL。报告写明 [L1] 至 [L6]、对应证据与 C、决策链、机会成本、风险边界及变更条件。禁止为了形式合格将不相关数字混入同一公式。

## 例如研究一只股票
1. 产品：谁用、谁付钱、替代品、实际售价、复购/留存、每单位交付成本。
2. 行业：市场真实需求、供应瓶颈、替代、竞争对手成本、未来产能、利润流向；用约束推导销量/份额/价格。
3. 公司：按产品分解收入，利润桥、现金流、资本强度、债务及资本配置、逐股价值。
4. 政策：适用法律、税率、许可、贸易、融资与需求传导；若影响小也说明证据。
5. 市场：当前价格与股数、净债务、相对基准、交易流动性；分价值研究与短期交易。
6. 预期：反向估值解隐含增长/利润率/回报，与自身情景比较；只在差异可信且成本后赔率可接受时提出条件性判断。
综合模型示例：可实现客户数 × 单位用量 × 净价 × 竞争后毛利率 − 履约、运营及必要资本投入 → 自由现金流 → 股权价值区间 → 当前价格的隐含条件 → 与宽基/现金的机会成本、催化、止损或失效条件。客户数、行业份额及同一产能不可重复计算；变量要有独立证据或明示假设。
