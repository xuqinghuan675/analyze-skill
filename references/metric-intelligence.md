# 指标穿透手册｜Metric Intelligence

> 本手册为 ANALYZE 的研究方法扩展；部分方法来自已读取的 Anthropic 视频，通用指标定义和跨领域扩展由研究员补充。具体公司数字、行业结论和政策事件必须重新查证，不沿用视频里的数字。
>
> 每遇到重要指标，先读这一页；不要把指标表机械填满。按研究对象、异常和决策选择有解释力的指标。

## 1. 指标不是结论：强制执行六问

1. 它实际上测量了什么？分子、分母、时间区间、单位、样本、会计/统计口径是什么？存量还是流量？实际值、年化值、预测值还是市场隐含值？
2. 它为什么会上升或下降？把公式拆成可变化的驱动量。分子上升、分母下降、结构变化、价格、数量、汇率、一次性项目分别检查。
3. 哪些情况会让同一个指标产生完全相反的判断？至少给一个正向机制和一个反向/失真机制。
4. 哪个其他指标能区分这两种解释？先找最便宜、最可靠的原始证据；必要时分客户、地区、产品、合同或季度。
5. 谁因此受益、谁承担成本或风险？它影响下一期利润、现金、供需、融资、控制权还是市场预期？多久传导？
6. 这变化市场是否已经知道？观察同口径历史、可比主体、当时预期和当前价格；写出判断被推翻的条件。

指标卡格式：
- 名称/英文缩写、来源文件与字段、截点/期间/单位、公式和口径；
- 直白含义、实际值及变化、历史/同行/预期基准；
- 可能机制 A/B、区分证据、计算或验证结果；
- 传导对象、对结论的影响、领先/滞后性、反证和更新条件。
发现陌生指标时按此格式自行补充。官方文档、会计准则、统计机构、交易所数据字典或合同优先于网络百科。

## 2. 公司：数字背后的生意

| 指标 | 口径与现实含义 | 看见变化后具体追什么 |
|---|---|---|
| Revenue 营收 | 期间确认的收入，非订单、现金流或GMV | 拆销量×实现单价、产品组合、地区、汇率、并购、确认方式。增长时追量价贡献和复购，不直接称需求增长。 |
| YoY / QoQ / CAGR | 同比、环比、复合年增速；CAGR=(期末/期初)^(1/n)-1 | 看基期、季节性、异常收购、可比口径；增长率高也可能因小基数。跨周期看绝对新增量。 |
| ARR / Run-rate | 合同经常性收入年化或近期收入年化，定义各公司不同 | 查真实已实现收入、合同期限、流失率、按量波动及未来兑现，不能直接代替会计营收。 |
| RPO / Backlog | 剩余履约义务/待交付订单，存在确认及取消口径差异 | 查合同是否可撤销、各年履约、客户质量、产能、递延与现金支付。 |
| NRR / GRR | 同一批老客期末收入/期初收入；NRR含扩张，GRR通常剔除扩张 | 拆提价、用量扩张、收缩、客户流失、分层集中度。高NRR还要看客户总数和竞争切换。 |
| ARPU / ARPA | 每用户/客户平均收入，确认活跃或付费分母 | 拆用户结构、价格、用量；平均值上涨可能是低价用户流失。 |
| Gross margin 毛利率 | (收入−收入成本)/收入 | 追单位成本、利用率、采购价、产品组合、折旧和成本分类；增收降毛利可能说明新增客户贡献低。 |
| Operating margin | 营业利润/收入 | 追研发、销售、管理、股权激励和规模杠杆；区分削减投入造成的暂时好看。 |
| Incremental margin | Δ经营利润/Δ收入（分母有意义时） | 衡量新增加业务是否赚钱；收入涨而利润降时，逐项桥接费用。 |
| Contribution margin | 每单位收入减真实变动成本 | 看新增一单、一个token、一个用户能留下多少钱；固定成本、折旧、容量投资另列。 |
| EBITDA / Adjusted EBITDA | 息税折旧摊销前利润及调整项 | 不是现金流；查资本开支、利息、营运资本、股权激励和反复出现的一次性调整。 |
| Net income | 扣除经营、融资、税等后的会计利润 | 查公允价值、非现金损益、少数股东权益与摊薄。和营业利润、OCF桥接。 |
| OCF | 经营活动现金流 | 拆净利润、非现金项目、应收应付及预收；正OCF可能来自客户预付款、延迟付款。 |
| FCF | 常见定义OCF−CapEx，注明口径 | 看维护和增长性资本开支、租赁付款、是否靠融资补缺，勿与利润等同。 |
| CapEx / Depreciation | 资本支出/折旧 | 建实际建设与投产计划；查使用寿命、折旧政策、技术迭代、产能利用率。 |
| R&D intensity | 研发费用/营收 | 比绝对金额、资本化研发、项目阶段和研发输出；单看占比不能判断创新能力。 |
| ROIC | 税后经营利润/平均投入资本，口径需统一 | 查增量ROIC、资本成本、投资周期、商誉及闲置资产；高收入增长不一定创造价值。 |
| Net debt / liquidity | 有息债务减可用现金/流动性 | 查受限资金、债务期限、契约、利率、担保、再融资和长期合同付款。 |
| Cash conversion cycle | DIO+DSO−DPO，库存/应收/应付周转天数 | 库存积压、客户回款质量、供应商信用变化；季节性及负营运资本分别解释。 |
| Customer concentration | 大客户收入/总收入或客户层分布 | 查客户合同、议价权、续约、交叉投资及终端独立需求。 |
| Share dilution | 完全稀释股数/历史股数变化 | 追期权、RSU、可转债、增发与优先股；公司市值上涨不必然等于每股收益上涨。 |

## 3. 估值与隐含预期

| 指标 | 现实含义 | 具体研究动作 |
|---|---|---|
| Market cap | 当前股价×流通外总股数（估值时关注完全稀释口径） | 核对股本类别与股数、时间；市值不是公司现有现金。 |
| EV | 股权价值+债务等−可用现金，按需要加少数股权/优先股 | 不同资本结构比较时用相同口径。 |
| P/E / Forward P/E | 股价/EPS或市值/归母净利润；历史与预测分母不同 | 亏损时不适用；拆盈利周期、一次性项目和增长。高P/E隐含未来预期，非单独定价结论。 |
| P/S / EV/Sales | 股权市值/营收或EV/营收 | 结合净利率/毛利率、资本强度和收入实现能力；同口径、同期间比较。 |
| EV/EBITDA | 企业价值/EBITDA | 重资本行业必须再看CapEx、租赁、现金流及资本回报。 |
| FCF yield | 股权口径FCF/股权市值，或企业口径FCF/EV | 严格匹配分子分母；区分一次性现金释放和可持续现金。 |
| DCF | 未来可分配现金流按适用折现率折现 | 先分解收入、利润率、再投资，再算敏感性、终值占比及稀释。 |
| Reverse valuation | 当前价格对应的未来增长/利润/回报门槛 | V_future=V_now×(1+r)^n；所需利润=V_future/合理P/E；所需营收=所需利润/净利率。注明假设，继续验证可实现性。 |
| IPO free float / lockup | 初始可交易股数、解禁时间与条件 | 查发行文件、配售、稳定价格安排、指数纳入规则；长期价值和短期供需独立研究。 |

例：假设市场给公司1000亿市值，当前收入100亿，成熟净利率20%、成熟P/E=25倍、5年目标年化收益10%，忽略分红与稀释。5年目标市值约1610.5亿，所需收入约322.1亿，隐含收入CAGR约26.4%。下一步不是给出买卖意见，而是去核验客户预算、供给、单位成本、竞争和融资能否支持这条路径。

## 4. 行业与技术：研究现实产出而非宣传

| 指标 | 含义 | 具体追查 |
|---|---|---|
| TAM/SAM/SOM | 理论需求、可服务市场、可获得市场（需自行定义） | 自下而上用实际客户数×预算×渗透率；排除无法服务、重复计算、没有付费能力的需求。 |
| Shipment / Sell-through | 出货量/最终销售量 | 查渠道库存、租赁、展示样机、退货、政府采购、真实持续使用；两者差值可能是渠道积压。 |
| Capacity / Utilization / Yield | 设计或可用产能、利用率、良率 | 查产线、设备交付、认证及合格品；产量=可用产能×利用率×良率（避免口径重复）。 |
| ASP | 实际平均售价=收入/销量（口径一致） | 看产品组合、折扣、合同价与现货价；份额上涨可能来自降价。 |
| Market share | 本主体销量/收入占对应市场比例 | 明确量/额份额、地域与产品等级；份额上升和利润下降并不矛盾。 |
| CR3 / HHI | 前三家份额合计/份额平方和 | 集中不代表永久议价能力；查产能扩张、替代、买方集中度与进入壁垒。 |
| Inventory days | 库存相对成本/销售速度 | 去库存还是需求崩塌，追价格、订单、终端销售和交货周期。 |
| 技术性能 | 吞吐、延迟、精度、功耗、可靠性、良率，按任务选取 | 同一工况、质量约束、成本与测试流程比较；区分实验室演示、真实生产和规模部署。 |
| 技术成熟度 | 技术能否稳定交付和商业运行 | 查运行小时、任务成功率、人工干预、故障、售后成本、认证与付费客户；不能用一次表演替代。 |
| 资本强度 | 投入资本或资本开支/收入/产能 | 查维护开支、资产寿命、折旧及单位产能回报，比较资本成本。 |

## 5. 产品：看用户为什么真付钱

| 指标 | 含义 | 下一层证据 |
|---|---|---|
| DAU/MAU | 日活/当期月活，活跃事件定义须查 | 区分打开应用、真实完成任务、付费、留存；机器人或活动引流可能抬高。 |
| Activation / Retention | 完成关键任务/同批用户持续使用 | 按入组时间、用户场景、支付与自然复购拆分，明确D1/D7/D30或其他窗口。 |
| Conversion | 从明确上一步到下一步的比例 | 找漏斗分母、失败环节、用户动机与实验对照，避免只看总转化。 |
| CAC / LTV | 增量获客成本/预期客户贡献价值 | CAC按渠道及付费客户算；LTV基于贡献利润、留存、时长及风险；不能默认无限寿命。 |
| Payback | CAC/每期新增客户贡献利润（简化） | 查获客款先付、现金回收时间和客户留存是否覆盖回本期。 |
| GMV / TPV / take rate | 平台成交额/支付额/收入或手续费占额 | 平台收入不是全额交易额；查补贴、渠道费用、欺诈损失、退款及支付网络。 |
| 可用性/SLA/故障率 | 可服务时间、服务承诺、真实异常 | 明确窗口和例外；99.999%年可用性约允许5.26分钟不可用（简单365天口径）。 |
| 用户 ROI | 原方案总成本−新方案总成本，加可量化收益 | 同等任务、质量、风险、人工复核、迁移与维护成本；明确谁付款、谁得益。 |

## 6. 政策与宏观：先拆口径再解释方向

| 指标 | 含义 | 下一层证据 |
|---|---|---|
| GDP / Real GDP | 经济产出/剔除价格变化后的产出 | 区分名义与实际、人均与总量、增速及贡献；查消费、投资、政府、净出口和修订。 |
| CPI / Core CPI / PCE | 不同口径消费价格变化 | 看权重、服务/住房/能源、基期、环比年化；价格水平和通胀率不同，核心指标非生活成本全貌。 |
| Unemployment / Participation | 失业者占劳动力比率/劳动力占工作年龄人口比例 | 结合就业人数、参与率、工时、工资、职位空缺；失业率下降可能来自退出劳动力市场。 |
| Policy rate / Dot plot | 央行政策目标利率/决策成员对未来利率的个人判断分布 | 区分现行政策、预测、市场预期；看中位数、分散、期限、前次变化、声明与发布会。点阵图不是利率承诺。 |
| Yield curve / Real yield | 不同期限利率/名义收益率扣除通胀预期的近似 | 拆未来短率预期、期限溢价和流动性；观察风险资产折现及实际融资条件。 |
| Fiscal deficit / Debt | 期间财政收支差/债务存量 | 查财政预算、到期利率、债务币种、税基、政府融资结构，不把赤字当债务。 |
| Dependency ratio | 按指定口径的人口抚养比或制度内缴费/领取人数关系 | 不混用人口年龄比和实际参保缴费比；追缴费工资、费率、领取金额、财政补贴和制度分层。 |
| Subsidy / tariff / coverage | 单位补贴或税费、覆盖对象 | 原文+预算+执行细则；实际影响=合格规模×参与率×单位金额（受供给、时限、预算约束）。 |
| 政策有效性 | 计划目标与真实执行结果的差异 | 查批准、拨款、实际支付、产出、对照组及替代效应；评估因果识别，而非事后归因。 |

## 7. 金融与加密市场：指标必须回到交易机制

| 指标 | 含义 | 下一层证据 |
|---|---|---|
| Volume / Turnover | 成交数量/成交金额或换手率（明确定义） | 结合方向、价格、深度、时段；成交量大不直接说明资金净流入。 |
| Spread / Depth | 最优买卖报价差/不同价位可交易数量 | 计算目标订单冲击与真实滑点；检查撤单、流动性碎片化与时段差异。 |
| OI | 未平仓合约数量或名义价值 | OI上涨说明新增净未平仓合约，不直接表明谁看多；价格、成交方向、资金费率和基差合看。 |
| Funding rate | 永续合约多空定期结算费率 | 先核实交易所方向、费率周期、历史分位；计算实际持仓成本及拥挤/套利解释。 |
| Basis | 衍生品价格−现货价格（常以比例或年化表示） | 查到期、融资、借币、交易摩擦；风险溢价不等于无风险利润。 |
| Liquidations | 触发强平产生的订单或统计金额 | 区分实际成交与估算；覆盖平台、时间、方向、是否存在级联；结合深度与后续价格。 |
| Volatility / ATR | 收益波动/真实波幅均值（ATR常以价格计） | 统一时间窗口、频率和单位；量化仓位、止损、滑点及不同状态下的策略表现。 |
| IV / Skew | 期权价格隐含波动率/不同执行价或Delta的波动率差 | 波动预期非方向预测；比较期限、偏斜、风险溢价、事件后波动收缩。 |
| ETF flow / On-chain flow | 按指定来源的申赎或链上转移 | 链上转账可能是内部地址迁移，ETF成交额也不是净申购；查发行方、交易所和标注规则。 |
| Sharpe / Max drawdown | 超额收益风险比/从峰值到谷值的最大跌幅 | 统一频率、费用、资金费率、复利、基准；查尾部损失、样本外及策略容量。 |

## 8. 预期：用预期差而非利好利空

| 指标 | 含义 | 下一层证据 |
|---|---|---|
| Consensus / surprise | 事前共识/实际值−事前共识 | 同一事件、时间截点与统计口径；追共识区间、修订、公布后的指引和历史反应。 |
| Earnings revisions | 对同一财年/季度盈利预测的修订 | 查修订广度、幅度、时间、业务驱动，区分滚动期间造成的变化。 |
| Implied probability | 从合约或模型反推的风险中性/市场价格所含概率 | 先查结算和费用、流动性、风险溢价及模型假设；不直接当真实概率。 |
| Implied move | 从期权价格/IV得到的幅度估计 | 不是方向和确定区间；核对到期、事件时点、实际历史幅度。 |
| Expected return | 各互斥情景的概率×净回报之和 | 概率总和为1，计交易成本；检查尾部损失与相关条件，数据不足只给范围。 |

## 9. 组合判读（优先找能排除解释的组合）

- 营收↑、毛利率↓：先算新增毛利与单位贡献；查量价、客户结构、采购价和产能利用率。
- 净利润↓、OCF↑：定位非现金损益及营运资本；再看FCF、未来付款和稀释。
- NRR↑、可撤销收入比例↑：留存与合同确定性分别评估；比较匹配期限的承诺付款和可实现收入。
- 出货↑、终端使用率↓、渠道库存↑：优先查渠道压货、展示/补贴采购、复购与实际工况。
- 市占率↑、ASP↓、ROIC↓：可能以价格换规模；查单位成本是否下降和竞争供给反应。
- 降息预期↑、股价↓：区分增长恶化引发的降息与通胀回落引发的降息，再看盈利修订和风险溢价。
- BTC价格↑、OI↑、资金费率走高：可能拥挤或套利增加；查现货成交、基差、跨平台和深度，不把组合当必涨/必跌信号。
- 财报超预期、股价↓：检验下一期指引、隐含增长、持仓、事件前涨幅及同时发布的信息。

每条组合只提供调查方向；必须由对应对象实际数据证实，禁止按符号自动得出投资结论。
