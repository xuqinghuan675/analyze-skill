# 视频研究：优先直接获取原字幕

按 2026-11-25 用户要求，默认使用已有字幕，不运行语音识别，也不下载视频或音频。获取失败就记录，不声称读过。自动生成字幕是 YouTube 现有轨道，不是本地模型推理；手工原字幕优先。

## 本地运行
字幕功能为可选依赖。在当前 Python 虚拟环境安装 `python -m pip install youtube-transcript-api yt-dlp`，或按原本地方式隔离安装至 .caption-tools/ 和 .tools/。
```powershell
python references\video\fetch_captions.py TVrzVLW5GbQ
```
输入可为 ID 或链接；支持多个视频、中文轨道筛选。工具先从字幕 API 读取，失败才调用 yt-dlp 的字幕元数据和 JSON3 轨道。输出至 references/video/captions/<video_id>/：captions.json（来源、语言、是否自动生成、时间戳）、transcript.txt 或 status.json（具体错误）。最新批次汇总 latest_run.json。缓存命中无需重复请求。只读取合法可访问字幕；不尝试绕过字幕关闭、付费、认证或站点限制。若视频没有可读取字幕，可明确建议使用作者提供的文字稿；本地语音识别仅在另行需要时采用。

## 学习流程
阅读一段有时间戳的真实字幕→找关键问题及指标→归纳研究者如何由现象推到机制→查指标官方定义或原件→抽象可迁移的条件、反证和调查动作→写入案例和指标手册。每期记录已读区间与未取得区间；视频观点不直接当一手事实。质量优先，优先公司财报、估值、货币政策、市场结构、行业供需等能提升研究能力的主题。
