# 行业专属 KPI 与原始证据导航
不是指标评分表。每一行是调查起点：取原始定义和至少一个实际值，拆量、价、成本、现金及竞争约束，再连到投资判断。依据对象选用，不机械全文读完。

| 行业 | 关键量与约束 | 优先来源及容易踩的坑 |
|---|---|---|
| SaaS/云 | ARR/GRR/NRR、付费客户/席位、用量价格、CAC payback、毛利、履约义务 | 10-K 分部及合同附注、官方计费/客户；ARR 不等于收入，NRR 不等于留存人数 |
| AI模型/算力 | 请求与 token、实际净价、GPU 利用率、推理单位成本、训练/推理 CAPEX、合同期限 | 产品 API 价格/服务条款、财报、供应合同；榜单分数不等于实际采用，签约不等于已付款 |
| 半导体/设备 | 晶圆投入×良率、节点/封装、利用率、ASP、交货期、设备装机基数/服务收入、客户集中 | 设备厂与晶圆厂财报/技术资料；名义产能不等于合格产能，设备订单须看取消 |
| 机器人/制造 | 节拍、良率、MTBF/停机、部署/维护成本、客户 ROI、产线实际产能 | 技术手册、客户验收/订单、成本明细；实验室成功不等于规模量产 |
| 零售/消费 | 同店销售=客流×客单近似、库存周转、坪效、门店单位经济、会员续费 | 财报运营数据、同店定义、价格与库存；同店排除门店范围、会员数是存量 |
| 平台/支付/广告 | 活跃付费、GMV/TPV、实际 take rate、损失/欺诈、广告填充与 CPM、交易频率 | 分部收入、交易条款、支付网络披露；GMV不是营收、补贴扣除及流量真实性 |
| 银行 | NIM、存款 beta、贷款增速、NPL/拨备、CET1、未实现资产损失、流动性 | Call Report、监管报表、利率重置；负债是经营投入，不套工业 EV |
| 保险 | 综合成本率、赔付发展、保费留存、浮存金成本、资产久期及监管资本 | 法定报表、准备金与投资组合；浮存金非免费，准备金估计风险 |
| 房地产/REIT | NOI、同店 NOI、入住率、租约滚动、FFO/AFFO、资本化率、融资期限 | 租约/资产列表、财报调节、地方成交；AFFO定义不统一，NAV对 cap rate 敏感 |
| 能源/矿业 | 产量、品位/回收率、储量、边际成本/维持支出、对冲、库存 | EIA/IEA/地质与技术报告、合同；资源量不等于可经济开采储量 |
| 医药/医疗器械 | 临床终点、成功概率/样本、批准/适应症、报销价格、专利、上市渗透、制造良率 | ClinicalTrials.gov、FDA/EMA、医保目录、公司披露；临床信号不是批准，不以 TAM 代收入 |
| 物流/航运/航空 | 运力、运价、装载率、周转、燃油/人力、资本支出 | 运价指数定义、公司运营、港口与监管数据；运量与运价共同变动，周期峰值不可外推 |
| 教育/服务 | 获客、转化、履约、退款、完课/结果、复购与人效 | 产品条款、监管许可、真实招生/交付数据；流水不等于收入，满意度不等于学习效果 |

对于陌生行业：先查两份专业原件/定义、两家可比公司的分部及关键指标；将物理技术约束、用户价值、单位经济、利润池和供给时滞制成 G2 卡。需要额外学科时从教材、标准、监管及同行评议材料补充；无法判断的技术问题明示能力缺口。
